### Langkah Langkah Praktikum
#### 1. Membuat Dokumen HTML, Membuat box element dan menambahkan CSS Float Property.
Persiapan membuat dokumen HTML dengan nama file lab4_box.html seperti berikut.Kemudian tambahkan kode untuk membuat box element dengan tag div. Lalu tambahkan deklarasi CSS pada head untuk membuat float element.

#### 2. Mengatur Clearfix Element
Clearfix digunakan untuk mengatur element setelah float element. Property clear digunakan
untuk mengaturnya.
<img src="https://github.com/aramli/Lab4Web/raw/main/Praktikum4/B.png" width="300"/><img src="https://github.com/aramli/Lab4Web/raw/main/Praktikum4/2.png" width="300"/><br>

#### 3. Membuat layout sederhana
Pada tahap ini dibuat struktur dasar website menggunakan elemen semantik HTML5 seperti header, nav, section, aside, dan footer. Struktur ini bertujuan agar halaman web lebih terorganisir dan mudah dipahami baik oleh pengguna maupun mesin pencari.Kerangka layout terdiri dari beberapa bagian utama yaitu:Header sebagai bagian judul website.Navigation untuk menu navigasi.Hero Section sebagai area informasi utama.MainContent sebagai area konten utama.Sidebar sebagai area widget tambahan.Footer sebagai bagian informasi penutup halaman.
<img src="https://github.com/aramli/Lab4Web/raw/main/Praktikum4/3.png" width="300"/><br>

#### 4. Membuat Navigasi
Menu navigasi dibuat menggunakan elemen <nav> yang berisi beberapa link halaman seperti Home, Artikel, About, dan Kontak. Selanjutnya diberikan styling CSS berupa warna latar, ukuran teks, efek hover, dan indikator halaman aktif sehingga navigasi terlihat lebih menarik.
<img src="https://github.com/aramli/Lab4Web/raw/main/Praktikum4/4.png" width="300"/><br>

#### 5. Membuat Hero Panel
Hero panel digunakan sebagai bagian utama yang pertama kali dilihat pengguna saat membuka website. Pada bagian ini ditambahkanHeading atau judul utama, Paragraf deskripsi, Tombol aksi (Learn More).Hero panel berfungsi untuk menyampaikan informasi penting secara singkat dan menarik.
<img src="https://github.com/aramli/Lab4Web/raw/main/Praktikum4/5.png" width="300"/><br>

#### 6. Mengatur Main Content dan Sidebar
Layout dibagi menjadi dua bagian menggunakan CSS Float. Main Content sebagai area utama untuk menampilkan isi halaman. Sidebar sebagai area tambahan yang berisi widget atau informasi pendukung. Pembagian ini membuat tampilan website lebih terstruktur. Sidebar diisi dengan widget yang terdiri dari Widget Header berisi daftar link. Widget Text berisi informasi tambahan. Widget membantu menampilkan informasi pendukung tanpa mengganggu konten utama.
<img src="https://github.com/aramli/Lab4Web/raw/main/Praktikum4/6.png" width="300"/><br>

#### 7. Mengatur Footer
Footer dibuat sebagai bagian penutup halaman website. Footer berisi informasi hak cipta dan identitas website. Selain itu diberikan styling warna gelap agar berbeda dengan bagian konten.
<img src="https://github.com/aramli/Lab4Web/raw/main/Praktikum4/7.png" width="300"/><br>

#### 8. Menambahkan Elemen pada Main Content
Pada tahap ini ditambahkan beberapa box konten yang terdiri dari Gambar berbentuk lingkaran, Judul konten, Deskripsi singkat serta Tombol View Detail. Penggunaan box content membuat informasi lebih mudah dibaca dan lebih menarik secara visual.
<img src="https://github.com/aramli/Lab4Web/raw/main/Praktikum4/8.png" width="300"/><br>


#### 9. Menambahkan Content Artikel
Bagian artikel ditambahkan menggunakan elemen <article>. Setiap artikel berisi Judul artikel, Gambar pendukung dan Paragraf isi artikel. Artikel ditata menggunakan CSS float agar gambar dan teks tersusun dengan baik.
<img src="https://github.com/aramli/Lab4Web/raw/main/Praktikum4/9.png" width="300"/><br>
